4Server vs Client Component

Server (ডিফল্ট)async/await, DB/API সরাসরি, secret নিরাপদ, JS বান্ডলে যায় না
ClientuseState, useEffect, onClick — ফাইলের শুরুতে "use client"
src/components/Counter.tsx
"use client";
import { useState } from "react";

export default function Counter() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + 1)}>ক্লিক: {n}</button>;
}
💡 নিয়ম: যতটা সম্ভব Server Component রাখো; ইন্টারঅ্যাকশন দরকার শুধু সেই ছোট অংশটা Client করো।

🔍 লাইনে লাইনে ব্যাখ্যা — কেন এটা ব্যবহার হলো

"use client"এই লাইনের পর ফাইল ব্রাউজারে চলে; এটা ছাড়া useState চালালে এরর
useState(0)n হলো বর্তমান মান, setN বদলানোর ফাংশন; বদলালে কম্পোনেন্ট আবার রেন্ডার হয়
onClick={() => setN(n + 1)}ক্লিক ইভেন্ট ব্রাউজারে ঘটে, তাই এটা Client-এই লাগে

5ডেটা ফেচিং, Server Action ও API

src/app/blog/page.tsx
// Server Component-এ সরাসরি fetch
export default async function Posts() {
  const res = await fetch("https://jsonplaceholder.typicode.com/posts?_limit=5");
  const posts: { id: number; title: string }[] = await res.json();
  return <ul>{posts.map(p => <li key={p.id}>{p.title}</li>)}</ul>;
}
