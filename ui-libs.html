1Headless UI কী?

Radix UI ও Base UI — দুটোই unstyled কম্পোনেন্ট লাইব্রেরি। লজিক, accessibility (কীবোর্ড, ARIA, ফোকাস) তারা সামলায়; স্টাইল তুমি Tailwind দিয়ে দাও।

Radix UIradix-ui প্যাকেজ; asChild দিয়ে কম্পোজ করা
Base UI@base-ui/react (MUI টিমের); render prop ও data-attribute স্টাইলিং
💡 নিচের কোডে ট্যাব বদলে দুটোর পাশাপাশি তুলনা দেখো।

2ইনস্টল

npm install radix-ui
npm install @base-ui/react
⚠️ পুরোনো Base UI প্রজেক্টে @base-ui-components/react নাম পাবে — নতুন প্রজেক্টে উপরেরটাই নাও।

পার্থক্যRadix: Overlay / Content — Base UI: Backdrop / Popup

🔍 লাইনে লাইনে ব্যাখ্যা — কেন এটা ব্যবহার হলো

Dialog.Rootখোলা/বন্ধ স্টেট এখানে থাকে; আলাদা useState লাগে না
Dialog.Triggerকীবোর্ড ও aria-সহ বাটন; চাপলে মডাল খোলে
Dialog.Portalমডালকে body-র শেষে রেন্ডার করে, তাই overflow বা z-index সমস্যা হয় না
Overlay / Backdropপেছনের ঝাপসা স্তর; বাইরে ক্লিকে বন্ধ হয়
Title ও Descriptionস্ক্রিন রিডার এ দুটো পড়ে মডালের উদ্দেশ্য বোঝে, তাই বাদ দিও না
Dialog.Closeবন্ধ করার বাটন; Esc চাপলেও বন্ধ হয়, লাইব্রেরি নিজে সামলায়
className="fixed inset-0 …"লাইব্রেরি কোনো স্টাইল দেয় না, ডিজাইন সম্পূর্ণ তোমার Tailwind-এ

4স্টাইল স্টেট ও Next.js-এ নিয়ম

<Dialog.Content className="data-[state=open]:animate-in">…
/* state: data-state="open" | "closed" */
<Dialog.Popup className="data-[open]:opacity-100 data-[starting-style]:opacity-0 transition">…
/* state: data-open / data-closed, data-starting-style */
✅ দুটোই ইন্টারঅ্যাকটিভ, তাই ব্যবহারের ফাইলে "use client" দিতে ভুলো না।
💡 বাকি কম্পোনেন্ট (Tabs, Dropdown Menu, Select, Tooltip) একই প্যাটার্নে: Root → Trigger → Portal → Content/Popup।

🔍 লাইনে লাইনে ব্যাখ্যা — কেন এটা ব্যবহার হলো

data-[state=open]: (Radix)Radix অবস্থা বোঝায় data-state="open|closed" দিয়ে, Tailwind-এ এটা ধরে স্টাইল দেওয়া যায়
data-[open]: (Base UI)Base UI-তে বুলিয়ান অ্যাট্রিবিউট data-open থাকে
data-starting-styleখোলার ঠিক আগের অবস্থা; transition বানাতে এটা দিয়ে opacity 0 থেকে শুরু করো
